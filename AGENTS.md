# Content Explorer for Bricks

Baseline: Content Explorer for Etch v2.2.2, commit 10391f183507da71d51f58ac44b4963f47deab68. Do not claim parity for Bricks data the adapter cannot resolve.

Minimum WordPress 7.0; PHP 8.4; tested up to 7.2. Keep headers, readme, and asset versions aligned.

Create a release/<version> branch for every release-worthy change. Before release, run all Plugin Check categories, PHP/JavaScript syntax checks, REST permission integration tests, and Bricks smoke tests. Record evidence and open gates in docs/validation.md.

Target WordPress.org. Retain local assets and license notices; do not bundle an external updater. Never commit credentials, test-site databases, purchased Bricks source, or generated archives.
